# Min webbplats - Tove Hansson

## Projeket

Det här projektet är en webbplats som jag har fått i uppgift att skapa på min utbildning vid Mittuniversitetet.
Webbplatsen innehåller information om mig själv, mina intressen och vägen till mina studier. Det finns
dessutom en flik med mina kontaktuppgifter om man skulle vilja höra av sig till mig.

## Frågor och svar:

### Vad är skillnaden mellan git add och git commit?

Svar: ´git add´ används för att välja vilka ändringar som ska finnas med i nästa commit.
´git commit´ sparar dessa ändringar i en ny version i Git och dess historik.

### Varför använder man branches istället för att arbeta direkt i main?

Svar: Branches/grenar gör att man kan utveckla och göra ändringar utan att påverka den stabila versionen av projektet, vilket är huvudgrenen, som även kallas för main.

### Vad händer rent praktiskt när man gör en merge?

Svar: En merge kombinerar ändringar från två branches/grenar. Ändringar som gjorts i en branch/gren som kallas "Dev" kan föras in/"mergas" in i huvudgrenen, "main".

### Vad är skillnaden mellan att pusha till Github och att publicera på Netlify?

Svar: ´git push´ sänder projektets commits till ett Git-repo på Github. Netfliy gör istället en publicering av webbplatsens filer så att webbplatsen kan nås via en vanlig webbadress.

### Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?

Svar: Man kan lägga filens namn eller sökväg i en ´.gitignore-fil´
